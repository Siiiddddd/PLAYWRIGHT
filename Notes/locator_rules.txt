If you already have a reference to a parent element, you can access its children directly using JavaScript properties. 
element.children: Returns a live collection of only element children (ignores text and spaces).
element.childNodes: Returns all child nodes, including text nodes (whitespace/line breaks)

Parent	           element.parentElement
Children	       element.children
First child	       element.firstElementChild
Last child	       element.lastElementChild
Next sibling	   element.nextElementSibling
Previous sibling   element.previousElementSibling
Ancestor	       element.closest(selector)
Descendants	       element.querySelectorAll(selector)
Contains	       parent.contains(child)
